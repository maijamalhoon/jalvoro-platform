# AI Insights global responsive reset

This change is presentation-only and keeps the current AI Insights APIs, finance calculations, consent, saved state, history, deterministic scenarios, and chat routing unchanged.

## Product structure

1. Compact global AI header
2. Intelligence workspace and financial briefing
3. Finance chat
4. Trust and evidence context

## Responsive behavior

- Mobile: single-column product flow, swipeable supporting tools and priority groups, safe-area-aware sticky chat composer, 44px-class touch targets
- Tablet: compact header controls and single-column briefing/action lane
- Desktop: balanced briefing and action layout
- Wide desktop: three priority lanes and paired financial pulse panels without stretching reading lines

## Visual system

- semantic neutral surfaces with one active accent
- no ambient orbit/grid decoration
- no decorative infinite animation
- solid dark-mode contrast instead of low-contrast glass
- logical flow for Urdu and Arabic RTL
- reduced-motion and no-animation preferences respected

## Content density

- duplicate capability cards removed
- intelligence appears before trust context
- repeated descriptions, captions, safety notices, quality issues, and timeline items are visually reduced
- scenario calculations remain available with shorter cards
- saved insight controls remain available while repeated messages are hidden
